# Presentasi RPL Numi

Halaman baru pada file Figma asli: **04 Presentasi RPL Numi**.

https://www.figma.com/design/y0iET9hEQwy0xMFtV95Pek/numi-lebih-lengkap?node-id=2038-3126

Terdapat 21 frame presentasi berukuran 1920 x 1080. Teks, diagram UML, dan contoh layar dapat diedit. Aset ilustrasi, font, dan variabel warna berasal dari file Numi asli. Halaman desain sebelumnya dipertahankan.

Isi mencakup deskripsi dan tujuan, aplikasi pembanding, UCDC lengkap beserta dua perbesaran, aktor, kebutuhan fungsional dan nonfungsional, teknologi, acuan kurikulum beserta alasan, timeline materi usia 6 sampai 12, empat diagram UML, UI/UX, dan pengujian. Slide progres dan langkah berikutnya tidak disertakan.

Timeline merupakan usulan titik awal penyajian, bukan aturan usia resmi kurikulum. Luas dan volume belum termasuk 12 topik MVP. Alur checkpoint per jawaban dijelaskan sebagai rancangan. Contoh UI landscape diberi label usulan adaptasi.

UCDC mengikuti sembilan blok Numi hasil kajian sebelumnya. Lapisan tersembunyi dari template lingkungan/CSR tidak disalin. Kalimat disederhanakan tanpa menghilangkan status validasi yang belum dilakukan.

Setiap slide telah diperiksa melalui render native Figma. Tinggi teks diperbaiki setelah render awal, kemudian seluruh slide dirender dan diperiksa lagi. Jarak contoh pada timeline diperbaiki dan diperiksa melalui render terakhir. Font yang digunakan: Cabin Sketch, Mali, dan Nunito untuk isi UML. Navigasi prototipe memakai nomor slide di kanan bawah untuk maju dan teks Sebelumnya untuk kembali.

Tidak ada file PPTX atau PDF yang diekspor pada tugas ini. Hasil utamanya adalah halaman presentasi editable pada file Design yang diminta.
