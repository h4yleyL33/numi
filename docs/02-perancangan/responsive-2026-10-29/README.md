# Numi: tema dan layar adaptif

Permintaan 29 Oktober 2026 mencakup UI aplikasi/rancangan Figma dan PPT. Usia tetap 6–12 tahun.

Ilustrasi latar memakai imageHash asli 35b889298a6cf125274183d5acc433f81bb37c91 dari Figma revisi. Aset portrait 851×1847 dipertahankan. Aset landscape 1600×900 merupakan potongan dekoratif dengan rasio tetap yang menampilkan laut dan mercusuar; tidak diregangkan. Teks dan komponen bukan bagian dari bitmap latar.

Rancangan Figma dibuat pada page 4028:30: enam layar target untuk tiap ukuran 844×390, 1024×768, dan 1440×900, total 18 frame. Komponen kartu dan tombol, font, variabel usia, serta alur dipakai ulang. Panel panjang dapat digulir pada ponsel landscape. Layar portrait sebelumnya tetap tersedia.

Aplikasi memakai latar bersama, palet laut/krem/kuning, lebar isi maksimum 1200, reflow cerita dan soal, navigasi samping pada ruang lebar, serta gulir untuk isi dan feedback layar pendek. Dukungan lintas perangkat akan diperiksa melalui widget test dan build web. Ini tidak menambah implementasi asesmen/checkpoint yang sebelumnya masih menjadi target.

PPT disunting langsung pada 1ezOODKHn9w5Uasykd3WNpgLs-vE_LWj8TKW-m7cYo4U. Ukuran tetap 960×540 (landscape 16:9), menggunakan aset latar yang sama dengan lapisan warna agar teks/tabel terbaca. Konten native tetap dapat diedit. Slide UI akan memperlihatkan variasi landscape.
