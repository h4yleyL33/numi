# Latar Numi

Ekspor dekoratif dari latar yang sudah dipakai dalam Figma Numi revisi, imageHash `35b889298a6cf125274183d5acc433f81bb37c91`.

- `numi-portrait.png`: 851×1847, ilustrasi utuh.
- `numi-landscape.png`: 1600×900, potongan berasio tetap pada bagian langit, laut, dan mercusuar. Tidak diregangkan.

Latar tidak memuat teks, tombol, atau screenshot antarmuka. Figma dan PPT memakai ilustrasi yang sama. Perizinan ilustrasi mengikuti aset sumber proyek; tidak ada klaim lisensi baru.
